# Сгенерированный документ {#the-generated-document}

Сервис на RustStream описывает себя документом AsyncAPI, а этот крейт дописывает в него то, что о
канале знает только Redis: какая структура несёт его сообщения и как эта структура настроена.

Включите фичу в обоих крейтах:

```toml
ruststream = { version = ">=0.7.0-rc.5, <0.8.0", features = ["macros", "asyncapi"] }
ruststream-fred = { version = "0.7", features = ["asyncapi"] }
```

В спецификации AsyncAPI есть привязка `redis`, и все четыре её объекта пусты: в них нет поля ни под
группу потребителей, ни под режим чтения, ни под режим доставки. Ключ привязки берётся из закрытого списка,
поэтому крейт пишет рядом расширение `x-ruststream-redis` - спецификация разрешает его ровно на том
уровне, где стоит привязка.

Подписка на поток сообщает группу и потребителя, через которых читает, свой режим чтения и порог
простоя, с которого перехватывают два режима с перехватом:

```json
--8<-- "crates/ruststream-fred/tests/fixtures/asyncapi_stream_channel.json"
```

Это тело по пути `channels.orders.bindings.x-ruststream-redis`, и тест в крейте сверяет документ
именно с этим файлом.

Список сообщает, подтверждает ли он доставки (`reliable`), на каком списке обработки лежит
незавершённая запись, пока он это делает, и в каком конверте едут его заголовки. Канал сообщает свой
режим доставки и то, является ли его адрес шаблоном. Издатель сообщает тот же словарь с другой
стороны: режим доставки, в котором уходит `PUBLISH`, срок жизни, который перевзводит запись в
список, конверт, который он пишет.

Каждое значение берётся только из дескриптора или политики, потому что документ строится до того,
как что-либо подключилось. Отсюда два следствия, о которых стоит знать. Версия сервера Redis не
попадает в документ: клиент узнаёт её при рукопожатии, а оно ещё не состоялось. И ни один секрет не
может дойти до документа, что важно, потому что документ публикуют и им делятся: в записи сервера
стоят хост и порт, на которые звонит клиент, со снятыми схемой, `user:password@`, номером базы и
строкой запроса.
