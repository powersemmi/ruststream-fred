# Транспорты

Redis передаёт сообщения тремя способами: поток хранит записи для групп потребителей, список
отдаёт каждую запись одному потребителю, канал не хранит ничего.

<Diagram name="transports" words={words} />

Поток - журнал, в который записи только добавляются. `XADD` добавляет запись под идентификатором,
который назначает сервер, и запись хранится, пока поток не усекут. Группа потребителей читает
поток со своим курсором, поэтому каждая из двух групп получает все записи. Внутри одной группы
каждая запись достаётся одному потребителю. Как группа учитывает доставленное, показывает страница
[Группы](groups.md).

Список - очередь. Издатель добавляет запись командой `LPUSH`, потребитель извлекает её с другого
конца, и извлечённая запись из Redis исчезает. Как надёжный список хранит запись, пока обработчик
не завершит её доставку, показывает страница [Очереди](queues.md).

Канал ничего не хранит. `PUBLISH` передаёт сообщение клиентам, подписанным в этот момент, а
клиент, который подпишется позже, его не увидит. Это показывает страница [Рассылка](broadcast.md).

Сервис читает каждый транспорт через собственный дескриптор:
[`RedisStream`](api:ruststream_fred::stream::RedisStream),
[`RedisList`](api:ruststream_fred::list::RedisList) и
[`RedisPubSub`](api:ruststream_fred::pubsub::RedisPubSub). Обработчик - одна и та же функция
`#[subscriber]` для всех трёх. Различается смысл подтверждения, как показывает страница
[Завершение](../settlement.md).
