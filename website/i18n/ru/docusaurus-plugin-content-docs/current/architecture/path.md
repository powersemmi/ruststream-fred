# Путь

Путь одной записи потока через сервис RustStream: добавление, чтение группой, доставка,
обработчик, ответ и `XACK`.

<Diagram name="path" words={words} />

Чтение возвращает до 64 записей за один обмен с сервером, и подписка отдаёт их по одной, прежде
чем читать снова. Пакетный обработчик вместо этого читает столько записей, сколько составляет
размер его пакета. Если в потоке нет ничего нового, чтение блокируется на интервал `block`
подписки, по умолчанию на пять секунд.

Каждая запись становится [`RedisMessage`](api:ruststream_fred::RedisMessage): поле `_payload` -
полезная нагрузка, а каждое поле `h:` - заголовок. Рантайм декодирует полезную нагрузку и
вызывает обработчик.

Ответ кодируется и публикуется командой `XADD` через соединение пула, а доставка завершается
после него. Запись, прочитанная из списка, и сообщение Pub/Sub начиная с доставки проходят тот же
путь, но завершаются так, как принято в их форме. Это показывает страница
[Завершение](settlement.md).
